# Text-based RPG Adventure Game
 
Collectfour items to defeat Murlocs. Health, melee damage, ranged damage, defense. Special abilities for combat advantage. Battle loop of player vs AI enemies. Heal or attack during battles. Six levels with increasing difficulty. Rewards include special items and abilities. Culminates in a final battle against Murloc.
